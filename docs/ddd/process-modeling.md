# CampusOverflow 流程建模 v1.0（Event Storming · Step 2）

> 团队：CampusOverflow 开发小组
> 来源：Lab3 事件风暴工作坊（第5周 / Sprint 1）
> 说明：为每个领域事件补齐蓝色"命令"卡、黄色"角色"卡、粉色"外部系统"卡。

## 认证（Identity）

| 领域事件 | 触发命令 | 角色 | 外部系统 |
|----------|----------|------|----------|
| 用户已注册 | 注册 RegisterUser | 学生/用户 | 学校统一身份认证(SSO/OAuth) |
| 用户已登录 | 登录 Login | 用户 | 学校统一身份认证(SSO/OAuth) |
| 教师认证已通过 | 审批认证 VerifyTeacher | 管理员/助教 | — |

## 问答（Q&A）

| 领域事件 | 触发命令 | 角色 |
|----------|----------|------|
| 问题已发布 | 发布问题 PostQuestion | 学生 |
| 问题已编辑 | 编辑问题 EditQuestion | 作者/管理员 |
| 回答已提交 | 提交回答 SubmitAnswer | 学长/任意用户 |
| 回答已采纳 | 采纳答案 AcceptAnswer | 提问者/老师 |
| 投票已投 | 投票 CastVote | 用户 |
| 评论已发布 | 发布评论 PostComment | 用户 |
| 内容已删除 | 删除内容 DeleteContent | 作者/管理员 |

## 声誉（Reputation）

| 领域事件 | 触发命令/机制 | 角色 |
|----------|---------------|------|
| 声誉已变更 | 响应问答领域事件（自动） | 系统规则引擎 |
| 徽章已授予 | 声誉达标判定（自动） | 系统 |
| 悬赏已开启 | 开启悬赏 OpenBounty | 提问者 |
| 悬赏已发放 | 发放悬赏 AwardBounty（自动） | 系统 |
| 悬赏已关闭 | 关闭悬赏（定时） | 系统定时任务 |

## 发现（Discovery）

| 领域事件 | 触发命令 | 角色 |
|----------|----------|------|
| 搜索已执行 | 搜索 Search | 用户 |
| 通知已发送 | 响应事件生成通知（自动） | 系统 |
| 相关问题已生成 | 响应发布问题（自动） | 系统 |

## 外部系统（粉色卡片）

- 学校统一身份认证（SSO/OAuth）：学号登录
- 邮件服务：注册验证、通知
- 全文检索服务（Elasticsearch / MySQL 全文索引）：搜索

## 热点（Hot Spot）

1. 采纳 → 声誉联动（跨上下文一致性，事务性发件箱解决）
2. 悬赏到期自动发放（防重复/防错误分配）
3. 防重复提问（发布时推荐相似问题）
