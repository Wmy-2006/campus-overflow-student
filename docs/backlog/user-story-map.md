# CampusOverflow 用户故事地图 v1.0

> 团队：CampusOverflow 开发小组
> 版本日期：2026-10-24
> 骨架主线：**用户从未注册到成为活跃贡献者**（注册 → 浏览 → 提问 → 回答 → 互动 → 成长）
> 本图为需求建模工作坊的文字版；可视化（Mural/白板）版本由团队在工作坊中产出并截图留存。

## 骨架（横轴：用户活动序列）

| 注册 | 浏览/搜索 | 提问 | 回答 | 互动 | 成长 |
|------|-----------|------|------|------|------|
| 用学号注册登录 | 关键词搜索问题 | 发布问题（标题/正文/标签） | 回答问题 | 点赞/投票 | 攒声誉积分/徽章 |
| 完善专业/年级资料 | 按课程/标签分类浏览 | 提问时推荐相似问题 | 提供成套方案（步骤+环境+避坑） | 评论追问 | 查看排行榜 |
| 教师申请认证 | 看热门/相关推荐 | Markdown 排版正文 | 采纳最佳答案 | 悬赏积分 | 收被@/被采纳通知 |

## 纵轴说明

- **顶部（核心/高频）**：注册登录、发布问题、回答、采纳 —— 对应 MVP（US-01~US-07）。
- **中部（重要）**：搜索、分类、投票、评论、认证、声誉、排行榜、悬赏 —— P1。
- **底部（增强）**：通知等 —— P2。

## Walking Skeleton（MVP 切片）

US-01 → US-03 → US-07 → US-05 → US-06，即：**登录 → 提问 → 看列表/详情 → 回答 → 采纳**，作为 Sprint 1/2 的交付主链路。
