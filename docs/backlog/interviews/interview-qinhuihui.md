# 访谈记录 1：专业课教师

- 访谈对象：<李老师>（<计算机学院/软件工程系>）
- 访谈人：秦慧慧
- 日期：2026-10-24
- 使用场景：老师在课后答疑、批改作业以及指导学生做项目时，如何解答学生的技术问题。

## 关键发现
- 他遇到问题时：主要依靠课堂统一讲解、课后在课程群集中答疑，或者让学生去参考经典的官方文档和教材。
- 他最在意的：**答案的严谨性、知识的系统性**，以及学生是否真正理解了底层的逻辑，而不是直接抄代码。
- 他吐槽的痛点：
  1. 很多学生问问题不经过思考，同一类基础问题在群里反复问，效率极低；
  2. 学生从网上（如 CSDN）复制来的代码有很多错误或过时的写法，导致项目跑不起来；
  3. 课后时间有限，无法一对一给几十个学生详细Debug。
- 他会用这个平台吗？为什么：
  会。如果平台能沉淀高质量的专业问答（如带有标签分类、可以搜索历史提问），能极大减轻教师的答疑负担。同时如果平台有“教师认证”或者“高信誉学长”机制，能保证答案的可靠性。
- 他期待的杀手功能：“能按课程或知识点进行分类的问答库，学生提问前能先搜到标准答案。”
