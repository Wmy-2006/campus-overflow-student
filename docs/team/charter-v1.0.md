# 团队章程 v1.0

> 生效日期：2026-10-23 ｜ 团队：CampusOverflow 开发小组
> 成员：吴梦瑶(PO) / 秦慧慧(SM) / 张馨月(Dev·文档) / 张丰舒(Dev·QA)

## 一、团队价值观
- 质量优先：任何提交经评审合并，不为赶进度牺牲代码质量。
- 主动沟通：遇阻塞第一时间在群里同步，不沉默硬扛。
- 相互负责：PR 及时评审，承诺的任务按时完成。
- 持续改进：每个 Sprint 结束做回顾，落实改进项。

## 二、沟通约定
- 异步沟通统一在团队 IM 群（微信群），重要结论同步到看板。
- 每日站会（SM 主持）：每人 3 句——昨天做了啥 / 今天做啥 / 有无阻塞。
- 工作时间约定：工作日 9:00-21:00 内回复群消息；紧急事项直接 @本人。
- 文档与讨论结论以 GitHub 仓库为唯一权威来源。

## 三、开发规约
- main 受保护，禁止直推；所有改动走分支 + PR + ≥1 人评审。
- 分支命名：feature/<功能>-<作者拼音>。
- Commit message 规范：`<type>(<scope>): <描述>`（docs/fix/feat/test 等）。
- 每个 Sprint 开始做 Planning，把 Backlog 拆成可执行 Task 分配责任人。
- 开发完成必须过 DoD 才算"完成"。

## 四、DoD（Definition of Done）初版
- [ ] 代码已提交并通过 PR 评审合并到 main
- [ ] 有对应单元测试且通过
- [ ] 本地编译/测试通过（后端 mvn test、前端 pnpm typecheck）
- [ ] 无遗留 TODO / 调试代码
- [ ] 关键设计有 ADR 或文档记录
